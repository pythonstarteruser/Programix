# 🐧 Programix

Programix is an independent Linux-based operating system project built on Ubuntu.

## 🚧 Project status

Programix is currently in early development.

The project is being developed and tested on a Fujitsu LIFEBOOK E744.

## 🎯 Goals

- Simple and friendly Linux desktop experience
- Programix-specific system tools
- Integrated update management
- Hardware and driver management
- Programix App Store
- Programix Recovery
- Strong Linux and Ubuntu compatibility

## 🧱 Base

Programix currently uses Ubuntu 26.04 LTS as its base.

Core technologies include:

- Linux kernel
- systemd
- APT/dpkg
- GNOME
- Wayland
- NetworkManager
- PipeWire
- fwupd

## 🧪 Development

The project is currently experimental.

Do not use development builds as your primary operating system.
